# Integration Scenario：S-DBG 当前账号数据恢复

| 项目 | 内容 |
| --- | --- |
| Scenario ID | `IS-SDBG-01` |
| Slice | `S-DBG` |
| Integration Contract | [`integration-contract.md`](integration-contract.md) `IC-SDBG-RESET@0.1` |
| 验证层 | `E2E Test` + `Slice Integration Test` |
| 状态 | `contract_locked` |

## 1. 目标

验证开发/联调环境中，候选人或 HR 只能清理当前账号的测试数据，成功后前端自动退出登录，其他账号和演示账号保持不变。

## 2. 前置数据

- 一个候选人账号和一个 HR 账号；
- 候选人至少有一份简历、附加资料和当前求职目标；
- HR 至少有一个岗位及其对象文件；
- 至少一个其他账号保留可核对数据；
- 无排队中或运行中的任务用于成功路径；另准备一条活动任务用于 409 路径。

## 3. 执行步骤与断言

1. 使用候选人登录，在“使用指南”页产品流程说明组件下方看到调试恢复按钮。
2. 点击按钮，按钮进入禁用/加载状态。
3. 接口返回成功后，前端清空工作区、退出登录并进入 `/login`。
4. 重新登录候选人，确认候选人的简历、资料和求职目标为空；确认 HR 数据和账号身份仍存在。
5. 对 HR 重复执行上述流程，确认岗位及其对象文件被清理，候选人数据不受影响。
6. 为当前账号制造活动任务，再点击按钮，确认返回 409，页面不退出登录且没有部分删除。
7. 关闭后端开关，确认接口返回 403；关闭前端开关，确认按钮不显示。
