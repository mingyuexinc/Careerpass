## 2. 交付目标

求职者和 HR 分别使用受控演示账号，从公共登录页完成登录，并进入与服务端确认身份一致的工作区。

## 3. 前置条件与演示数据

- 启动 Docker Compose 基础服务、数据库迁移、后端和前端开发服务；后端就绪检查为 `/health/ready`。
- 前端地址为 `http://localhost:5173/login`，通过 Vite 代理访问 `/api/v1`。
- 数据库已经存在启动时初始化的受控演示账号；不执行注册流程或临时脚本替代初始化。
- 演示账号：`candidate_01 / 123`，角色 `candidate`；`hr_01 / 123`，角色 `hr`。
- 不要求预置简历、岗位或其它业务数据；登录成功只验证认证结果和工作区路由。

## 4. 演示步骤与预期结果

| 步骤 | 操作 | 预期系统结果 | 预期页面结果 |
