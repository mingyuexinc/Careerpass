## 1. 交付目标

在求职者已登录的前提下，进入资料页并一次选择合法 PDF、Markdown、JPG、PNG 以及一个不合规文件。系统逐文件处理，前端先展示 `ready`；成功资料进入资料列表，失败文件不持久化，并通过一次性错误 Toast 提示。

```text
求职者登录
→ 进入资料上传页
→ 选择多份附加资料
→ 前端显示 ready
→ 后端逐文件保存
→ 成功资料进入列表，失败通过一次性错误 Toast 提示
→ 成功资料进入列表
```

## 2. 前置条件与演示数据

- S01 求职者真实登录和身份恢复已通过；
- 前端开发服务器、后端服务、PostgreSQL 和受控对象存储可用；
- 准备一份合法 PDF、一份合法 Markdown、一份合法 JPG、一份合法 PNG；
- 准备一个不支持的文件格式或超过 10 MB 的文件；
- 当前 Candidate 初始资料列表可控且没有同内容重复资料。
