| 项目 | 内容 |

| 关联 Slice | `S-07` |
| Integration Contract | [`integration-contract.md`](integration-contract.md) `IC-S07-AGENT-START@0.1` |
| 场景类型 | `frontend_visible` |
| 交付状态 | `integration_delivered` |

## 1. 交付目标

已登录求职者在求职目标模块中通过顶部菜单进入创建页或查看页。创建页负责保存目标并启动 Agent；查看页以只读列表展示当前目标记录。S-07 绑定启动时有效的当前简历，使 Agent 进入 `running`；可用岗位检查、匹配和投递记录属于 S-08，不作为本场景的成功条件。

```text
求职者登录
→ 进入求职目标模块
→ 通过顶部菜单进入求职目标创建或查看
→ 查看页以列表行展示当前求职目标
→ 返回创建页并点击启动 Agent
→ 启动成功后不展示匹配过程，进入求职进度页查看首轮结果
→ 目标在创建页变为只读；查看页保持三列只读记录
```

## 2. 前置条件与演示数据

- S-01 求职者真实登录可用。
- 当前 Candidate 已有 `active` 求职目标。
- 当前 Candidate 有解析成功且具备匹配资格的简历画像。
- 不要求存在可用结构化 JD；JD 检查由 S-08 负责。
- 当前目标没有 `running` 或 `finished` 运行上下文。

最小演示数据集：

| 数据集 | 必要条件 | 用途 |
| --- | --- | --- |
| `s07-startable` | `active` 目标、解析成功简历、`matching_ready` 画像、无当前运行上下文 | 验证首次启动 |
| `s07-without-jd` | 与 `s07-startable` 相同，且不准备可用结构化 JD | 证明 JD 不属于 S-07 前置条件 |
| `s07-repeat-start` | 已存在 `running` 运行上下文 | 验证重复请求幂等 |
| `s07-not-ready` | 无目标、解析中/失败简历或 `matching_not_ready` 画像之一 | 验证按钮禁用和通用状态 |
| `s07-finished` | 已存在 `finished` 运行上下文 | 验证不能开启新运行 |

## 3. 演示步骤与预期结果

| 步骤 | 操作 | 预期系统结果 | 预期页面结果 |
| --- | --- | --- | --- |
| 1 | 求职者进入求职目标模块 | 查询当前用户目标和当前启动状态 | 顶部显示“求职目标创建/查看”菜单，默认进入创建页 |
| 2 | 切换到求职目标查看 | 复用 S-06 当前目标查询 | 以横向条形列表展示当前目标；当前版本正常显示一行，仅显示目标岗位、目标 Offer 数量和创建时间，不显示配置和启动控件 |
| 3 | 返回创建页并点击启动 Agent | S-07 校验、绑定当前简历并创建或幂等复用运行上下文；启动成功后由 S-08 同步完成首轮匹配与投递 | 不展示匹配过程；进入进度页查看投递结果、匹配得分和推荐理由 |
| 4 | 刷新页面或重复提交启动 | 不创建第二个运行上下文 | 两个子页面均能查询目标，编辑入口保持禁用 |
| 5 | 检查当前投递结果 | S-07 不直接创建匹配结果或投递记录；启动链路完成后由 S-08 同步提供结果 | 页面不以 S-07 的成功结果伪造投递岗位；进入进度页查看 S-08 生成的投递结果 |

| 3 | 返回创建页并启动 Agent | 真实 API 创建或复用当前 `running` 运行上下文；S-08 在启动链路中同步完成首轮匹配与投递 | 启动页不展示匹配过程；进入进度页查看投递结果、匹配得分和推荐理由 |
