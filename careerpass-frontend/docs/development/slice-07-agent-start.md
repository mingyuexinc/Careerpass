# S-07 前端页面与交互设计

> 状态：`integration_delivered`。页面整改已完成，并通过 `IS-S07-01` 页面联调；认证会话只在当前浏览器会话内恢复，不保存密码。
>
> 业务边界以 [`../../../docs/business/business-baseline.md`](../../../docs/business/business-baseline.md) 和后端 S-07 Slice 规格为准；跨端字段以 [`../../../docs/integration/slices/slice-07-agent-start/integration-contract.md`](../../../docs/integration/slices/slice-07-agent-start/integration-contract.md) 为准。

## 1. 页面目标

在求职目标模块中完成以下闭环：

- 通过顶部横向菜单切换“求职目标创建”和“求职目标查看”。
- 创建页完成求职目标配置和 Agent 启动操作。
- 查看页以只读列表展示当前用户自己的目标记录；当前版本最多一条。
- 每条目标记录使用横向条形布局，仅展示目标岗位、目标 Offer 数量和创建时间。
- S-07 启动成功后展示运行中状态和约定文案。
- Agent 运行中或已结束后，当前目标保持可查看但不可编辑。
- 不展示匹配资格详情、结构化 JD、匹配结果或投递记录。

S-07 只负责创建运行上下文并使 Agent 进入 `running`；S-08 负责后续岗位检查、匹配和投递记录，启动链路不在前端展示匹配过程。

## 2. 页面结构

### 2.1 页面级菜单

```text
┌────────────────────────────────────────────────────────────┐
│ 页面标题：求职目标                                          │
├──────────────────────────────┬─────────────────────────────┤
│ 求职目标创建                  │ 求职目标查看                  │
└──────────────────────────────┴─────────────────────────────┘
│                    当前菜单对应的子页面内容                  │
```

- 菜单使用统一应用外壳、白色卡片、橙色激活态和设计令牌。
- 两个菜单项宽度一致，激活项使用背景和边框共同表达。
- 旧路径 `/candidate/job-goal` 重定向到 `/candidate/job-goal/create`。

### 2.2 创建页

- 页面只包含目标配置表单和 Agent 状态/启动区域。
- Agent 状态卡采用内容区 + 操作区结构，长文案不能挤压按钮。
- 按钮禁用时使用通用状态说明，不展开匹配资格、画像或 JD 原因。
- Agent 运行中或已结束后，目标编辑区只读。

### 2.3 查看页

- 页面只包含当前用户目标的只读记录列表。
- 每条记录作为一个独立行展示岗位、Offer 数量、筛选条件、状态和时间。
- 当前版本 S-06 只有一个当前目标，因此列表正常显示一行；不代表支持目标历史。
- 无目标时显示空状态和“去创建求职目标”入口。

### 2.4 移动端

- 顶部菜单保持横向双项布局，不产生横向页面溢出。
- 创建页表单和 Agent 状态卡按单列排列。
- 查看页记录保持三列横向排列；窄屏通过列表区域横向滚动，不改变字段顺序。
- 主启动按钮在窄屏下使用整行宽度。
- 加载、成功和通用提示不改变页面主结构。

## 3. 状态矩阵

| 页面状态 | 创建页表现 | 查看页表现 | 主要操作 |
| --- | --- | --- | --- |
| 加载中 | 显示加载状态 | 显示加载状态 | 禁止编辑和启动 |
| 无目标 | 显示目标编辑表单，启动按钮禁用 | 显示空状态和创建入口 | 创建并保存目标 |
| 目标已保存但条件未满足 | 显示通用不可启动状态，按钮禁用 | 显示一条只读目标记录 | 修改目标或补充资料 |
| 可启动 | 显示可启动状态和启动按钮 | 显示一条只读目标记录 | 启动 Agent |
| 启动提交中 | 按钮显示提交中并禁止重复点击 | 保持目标记录展示 | 等待服务端结果 |
| 已启动/运行中 | 显示成功文案，目标编辑区只读 | 保持三列只读记录，不增加状态字段 | 只能查看目标 |
| 已结束 | 显示 Agent 已结束，启动按钮禁用 | 保持三列只读记录，不增加状态字段 | 查看目标记录 |
| 查询失败 | 显示可恢复的通用错误 | 不显示不完整目标内容 | 重试查询 |
| 启动竞态 | 不建立“启动失败”业务状态，重新读取状态 | 以服务端最新状态为准 | 重试或刷新 |

“尚未满足启动条件”不展开具体缺失字段，也不展示 `matching_readiness`、画像字段或 JD 条件。正常前端路径只在条件满足时允许提交启动；服务端竞态错误仅作为通用操作反馈处理。

## 4. 目标记录字段

查看页每行仅展示：

- 目标岗位名称；
- 目标 Offer 数量；
- 创建时间；

不得展示：

- 岗位筛选条件、目标业务状态和最近更新时间；
- 简历原文、联系方式或画像字段；
- 匹配资格详情、可用岗位 JD 或匹配分数；
- 匹配结果、投递记录或内部运行路径。

## 5. 数据流和前端边界

```text
求职目标模块加载
  → S-06 GET 当前求职目标
  → S-07 GET 当前运行状态
  → 父级菜单渲染
  → 创建页或查看页组合安全投影

点击启动
  → 前端 Action 校验本地可见条件并防重复提交
  → S-07 POST 当前 Agent 启动
  → 以服务端返回的 running 更新页面
  → 创建页进入只读状态；查看页刷新后恢复三列只读记录
```

- 前端状态不能单独形成 Agent 已启动事实。
- 启动成功后不在本地创建匹配结果、岗位或投递记录。
- Mock Repository、HTTP Repository 和页面都只消费锁定 Contract 定义的字段。
- S-07 的启动 Action 返回运行上下文安全摘要，不返回完整工作区快照。

## 6. 视觉和可访问性要求

- 复用 [`../design/design-guidelines.md`](../design/design-guidelines.md) 的浅灰背景、白色卡片、橙色主操作色、统一圆角和阴影。
- 每个子页面只突出当前页面的主要行动；运行中和已结束使用统一状态色与文字表达。
- Agent 运行中状态沿用 HTML 原型：绿色文字、绿色指示点、12px 字号和 7px 间距。
- 禁用按钮同时提供简短的状态说明，不能只降低透明度。
- 查看页不提供编辑、保存或启动控件；记录行不增加超出裁决范围的状态字段。
- 目标列表只保留主容器，使用表头加紧凑横向记录行；记录行橙白交替，文字颜色按背景适配，悬停时仅增加轻量反馈。
- 启动提交中、成功和通用竞态提示应可被键盘和辅助技术感知。
- 长岗位名称和筛选条件应换行或截断，不得破坏菜单、表单或列表行布局。
