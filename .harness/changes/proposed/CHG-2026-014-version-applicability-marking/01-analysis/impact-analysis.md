# 影响分析

## 受影响模块与边界

| 模块 | 影响 | 所有权/权限影响 | 备注 |
| --- | --- | --- | --- |
| 接口协议 | 标记接口为 MVP 或 Deferred | 不改变现有授权规则 | Deferred 不得实现 |
| 数据模型 | 标记表、字段和约束适用版本 | 不改变既有归属约束 | Deferred 不得进入 MVP 迁移 |
| 认证 | 区分 Access Token 与 Refresh Token 设计 | 当前身份解析仍为 MVP | 会话持久化延期 |

## 契约与数据影响

- API：仅文档标记，不新增运行时路由。
- 数据库与 Alembic：仅文档标记，不执行 DDL。
- Redis/Celery：无。
- LLM、Prompt、追踪脱敏：无直接影响。

## 风险与缓解

| 风险 | 等级 | 缓解措施 |
| --- | --- | --- |
| 适用范围标记与 MVP 基线不一致 | medium | 以 CHG-2026-013 的范围裁决为唯一依据。 |
| Deferred 设计被错误实现 | high | 评审与测试计划中明确排除 Deferred 接口和迁移。 |
