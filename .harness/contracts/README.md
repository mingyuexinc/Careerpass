# 跨开发包契约注册表

本目录是跨模块 HTTP、内部 Service 边界、任务记录、事件和共享状态契约的唯一登记入口。

## 使用规则

- 每个契约必须具有唯一 `id` 和不可原地漂移的 `version`。
- `registry.yaml` 只登记契约索引、参与开发包、状态和摘要；字段与责任定义只保存在契约文件中。
- `draft` 只能用于阶段 1–3 讨论；`locked` 必须由所有生产者/消费者开发者联合批准；`superseded` 不得作为阶段 4/5 的实现前置。
- 契约锁定后计算文件摘要并写入注册表及参与包台账。语义变化必须创建新版本，或让所有参与包回退后重新锁定。
- 需求、方案、数据、任务和验证文档必须引用同一契约 ID/版本，不得复制后扩展字段或改变生产/消费语义。
