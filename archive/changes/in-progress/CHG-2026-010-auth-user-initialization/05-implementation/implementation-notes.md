# 实现说明

认证链路已实现并接入 API。数据访问保持在 Repository 层；Service、依赖注入和路由不直接访问 ORM Session。用户与候选人创建为单事务操作，认证后的身份由数据库关联复核。

历史实现曾包含 Redis 认证限流。该能力已于 2026-07-31 按受控 Demo 范围裁决移除；认证路由不再直接使用 Redis，相关历史验证结论不得作为当前认证模块验收依据。

密码契约已按阶段 1/3 裁决对齐为非空且最长 128 字符。认证请求仍使用 `SecretStr`，删除大小写、数字和特殊字符组合校验；scrypt 哈希、JWT、Repository、数据库结构和统一响应保持不变。

本变更包内的 SQL 仅用于审阅；实际迁移入口为工程中的 Alembic revision。
