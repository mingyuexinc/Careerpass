# 接口与数据模型版本适用范围标记

## 变更概述

在接口协议和数据模型中新增 `MVP` / `Deferred` 版本适用范围标记，明确完整设计中哪些能力属于当前 MVP 实现范围，哪些能力延期至后续阶段。

## 影响模块

- 认证与会话管理
- 求职者资料与消息附件
- 所有 MVP 核心业务模块

## 数据库变更

无。本次仅标记数据模型中对象的版本适用范围；`Deferred` 对象不得纳入 MVP 数据库迁移。

## API 变更

无。本次仅标记接口的版本适用范围；`Deferred` 接口不得纳入 MVP 实现或验收。

## Redis 变更

无。

## 关键约束

- MVP 范围文档是范围裁决的最高依据。
- 已设计但标记为 `Deferred` 的接口与数据库对象不得成为 MVP 开发依赖。
- 标记为 `MVP` 的能力仍须遵守既有数据模型、接口协议、状态机与安全红线。

## 回滚方案

移除两份文档中的版本适用范围说明和标记，并删除本变更记录目录。
