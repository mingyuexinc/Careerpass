# 影响分析

## 受影响模块与边界

| 模块 | 影响 | 所有权/权限影响 | 备注 |
| --- | --- | --- | --- |
| 全部 MVP 模块 | 统一裁决本期能力与延期能力 | 归属校验不可降级 | 作为任务拆分前置依据 |
| 认证 | 仅短期 Access Token | 不得把会话持久化作为 MVP 阻塞 | Refresh Token 为 Deferred |
| 投递与沟通 | 仅系统内状态变更与模拟沟通 | 禁止真实对外副作用 | 后续须增加授权与审计 |

## 契约与数据影响

- API：仅定义 MVP 必需接口；Deferred API 不得进入本期验收。
- 数据库与 Alembic：Deferred 表和字段不得作为 MVP 迁移前置。
- Redis/Celery：仅在具体 MVP 任务使用时成为条件依赖。
- LLM、Prompt、追踪脱敏：LLM 结果必须结构化校验，敏感信息最小化。

## 风险与缓解

| 风险 | 等级 | 缓解措施 |
| --- | --- | --- |
| MVP 范围膨胀 | high | 每项任务开始前按本文档裁决。 |
| 为演示绕过安全边界 | high | 将权限、隐私、幂等和状态机列为不可降级约束。 |
| 延期能力误入迁移或接口 | medium | 在接口和数据模型中标记适用版本。 |
