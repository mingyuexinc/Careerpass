# 求职过滤条件契约修订

## 变更概述

将岗位过滤条件明确为求职目标的内嵌 `filter_conditions` 值对象，并统一其 JSON 字段名、数组类型和可选性约定。

## 影响模块

- 求职目标管理
- 岗位匹配
- AI 求职沟通

## 数据库变更

无新增数据库字段；补充既有 `job_goal.filter_conditions` JSONB 字段的结构说明。

## API 变更

`POST /api/v1/job-goals` 新增 `filter_conditions` 必填请求字段；该对象可传入 `{}`，内部条件均可省略。

## Redis 变更

无。

## 关键约束

`include`、`exclude` 及所有子字段均可省略；未提供的字段不参与岗位过滤。

## 回滚方案

恢复本次文档修改，不涉及运行时数据或数据库结构回滚。

## 关联与实施状态

- 关联需求/变更包：无。
- 当前状态：已确认，待实现。

## 验收标准

- 创建求职目标接口接受必填的 `filter_conditions` 对象及其可选子条件。
- 岗位匹配仅将已提供的条件应用于过滤逻辑。
