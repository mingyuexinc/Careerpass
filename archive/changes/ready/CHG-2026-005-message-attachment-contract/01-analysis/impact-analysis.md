# 影响分析

## 受影响模块与边界

| 模块 | 影响 | 所有权/权限影响 | 备注 |
| --- | --- | --- | --- |
| communication | 消息关联独立附件资源 | 经消息到会话的归属链校验 | 删除消息级联删除附件。 |
| document-processing | 附件复用文件与解析元数据 | 不直接按附件 ID 越权读取 | 解析状态必须可追踪。 |
| repository | 封装附件读写与归属校验 | 必须校验当前候选人 | 禁止 Service 直接访问 Session。 |

## 契约与数据影响

- API：附件上传与查询接口将在实施设计中定义；消息仅表达 `attachment_ids`。
- 数据库与 Alembic：需要附件表、消息外键、索引和级联约束，实施前创建 `04-data/` 审阅产物。
- Redis/Celery：附件解析任务需幂等、可重试和可追踪。

## 风险与缓解

| 风险 | 等级 | 缓解措施 |
| --- | --- | --- |
| 仅凭附件 ID 导致跨候选人访问 | high | Repository 沿消息归属链执行同事务校验。 |
