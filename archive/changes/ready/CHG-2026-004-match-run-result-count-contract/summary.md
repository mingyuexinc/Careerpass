# 匹配批次结果数量契约修订

## 变更概述

统一岗位匹配批次的结果数量字段为 `result_count`，表示本次匹配批次生成的匹配结果数量。

## 影响模块

- 岗位匹配
- 匹配结果查询

## 数据库变更

数据模型将 `total_jobs` 统一命名为 `result_count`；实际数据库实施时须通过迁移重命名该列。

## API变更

无。

## Redis变更

无。

## 关键约束

`result_count` 不是匹配轮次序号，也不是全量岗位数量，仅表示该 `match_run` 产生的匹配结果数量。

## 回滚方案

实际数据库迁移的回滚将 `result_count` 重命名回迁移前的字段名；本次仅修订文档契约。

## 关联与实施状态

- 关联需求/变更包：无。
- 当前状态：已确认，待实现。

## 验收标准

- 匹配批次的持久化模型和查询结果统一使用 `result_count`。
- `result_count` 等于该批次实际生成的匹配结果数量。
